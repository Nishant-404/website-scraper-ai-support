# Website Scraper AI Customer Support

An intelligent web scraping system that creates AI-powered customer support bots by learning from client websites.

## Project Structure

- `scraper/` - Web scraping engine and crawlers
- `processor/` - Data cleaning and structuring pipeline
- `ai-training/` - AI model training and data preparation
- `support-bot/` - Customer support chatbot implementation
- `dashboard/` - Analytics and management interface
- `docs/` - Documentation and guides
- `tests/` - Test suites for all components

## Features

- Intelligent web crawling with respect for robots.txt
- Content extraction and cleaning
- AI training data generation
- RAG-based customer support bot
- Real-time knowledge base updates
- Multi-language support
- Analytics and performance tracking
