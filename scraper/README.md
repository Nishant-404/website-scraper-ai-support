# Web Scraper Module

Handles intelligent crawling and content extraction from client websites.

## Components

- `crawler.py` - Main crawling engine
- `extractors/` - Content extraction for different formats
- `utils/` - Helper functions and utilities
- `config/` - Scraping configurations and rules

## Features

- Respectful crawling with rate limiting
- Multi-format content extraction (HTML, PDF, etc.)
- Duplicate detection and filtering
- Sitemap parsing
- Dynamic content handling (JavaScript-rendered pages)
