# Data Processor Module

Cleans, structures, and prepares scraped content for AI training.

## Components

- `cleaner.py` - Content cleaning and noise removal
- `structurer.py` - Data organization and categorization
- `embeddings/` - Vector embedding generation
- `qa_generator.py` - Q&A pair creation from content

## Features

- HTML tag removal and text extraction
- Content categorization (FAQ, products, policies)
- Automatic Q&A generation
- Vector embeddings for semantic search
- Data validation and quality checks
