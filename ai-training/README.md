# AI Training Module

Prepares training data and manages AI model training for customer support.

## Components

- `data_prep.py` - Training data preparation
- `fine_tuning/` - Model fine-tuning scripts
- `rag_setup/` - Retrieval-Augmented Generation setup
- `evaluation/` - Model performance evaluation

## Features

- Training data formatting for various AI models
- Fine-tuning pipelines for custom models
- RAG system implementation
- Model evaluation and benchmarking
- Continuous learning from new interactions
